# 2013 年全国硕士研究生招生考试数学一真题

## 一、选择题

### 第 1 题

已知极限  $\lim_{x \to 0} \frac{x - \arctan x}{x^k} = c$，其中  $k, c$ 为常数，且  $c \neq 0$，则 ( )

A. $k = 2, c = -\frac{1}{2}$.

B. $k = 2, c = \frac{1}{2}$.

C. $k = 3, c = -\frac{1}{3}$.

D. $k = 3, c = \frac{1}{3}$.

<!-- source: 【横版】10-26年数一真题套卷做题本.pdf; PDF 第 71 页 -->

### 第 2 题

曲面  $x^{2} + \cos(xy) + yz + x = 0$ 在点  $(0,1,-1)$ 处的切平面方程为 ( )

A. $x - y + z = -2.$

B. $x + y + z = 0.$

C. x - 2y + z = -3.

D. x - y - z = 0.

<!-- source: 【横版】10-26年数一真题套卷做题本.pdf; PDF 第 72 页 -->

### 第 3 题

设  $f(x) = \left| x - \frac{1}{2} \right|$,  $b_n = 2 \int_0^1 f(x) \sin n\pi x \, dx$ ( $n = 1, 2, \cdots$). 令  $S(x) = \sum_{n=1}^{\infty} b_n \sin n\pi x$, 则  $S\left(-\frac{9}{4}\right) = (\quad)$

A. $\frac{3}{4}$.

B. $\frac{1}{4}$.

C. $-\frac{1}{4}$.

D. $-\frac{3}{4}$.

<!-- source: 【横版】10-26年数一真题套卷做题本.pdf; PDF 第 73 页 -->

### 第 4 题

设  $L_1: x^2 + y^2 = 1$,  $L_2: x^2 + y^2 = 2$,  $L_3: x^2 + 2y^2 = 2$,  $L_4: 2x^2 + y^2 = 2$ 为四条逆时针方向的平面曲线。记  $I_i = \oint_{L_i} (y + \frac{y^3}{6}) \, \mathrm{d}x + (2x - \frac{x^3}{3}) \, \mathrm{d}y$ ( $i = 1, 2, 3, 4$)，则  $\max\{I_1, I_2, I_3, I_4\} = (\quad)$

A. $I_1$.

B. $I_2$.

C. $I_3$.

D. $I_4$.

<!-- source: 【横版】10-26年数一真题套卷做题本.pdf; PDF 第 74 页 -->

### 第 5 题

设 A, B, C 均为 n 阶矩阵, 若 AB = C, 且 B 可逆, 则 ( )

A. 矩阵 C 的行向量组与矩阵 A 的行向量组等价.

B. 矩阵 C 的列向量组与矩阵 A 的列向量组等价.

C. 矩阵 C 的行向量组与矩阵 B 的行向量组等价.

D. 矩阵 C 的列向量组与矩阵 B 的列向量组等价.

### 第 6 题

矩阵  $\begin{pmatrix} 1 & a & 1 \\ a & b & a \\ 1 & a & 1 \end{pmatrix}$ 与  $\begin{pmatrix} 2 & 0 & 0 \\ 0 & b & 0 \\ 0 & 0 & 0 \end{pmatrix}$ 相似的充分必要条件为 ( )

A. a=0, b=2.

B. a=0, b 为任意常数.

C. a=2, b=0.

D. a=2, b 为任意常数.

### 第 7 题

设  $X_1, X_2, X_3$ 是随机变量, 且  $X_1 \sim N(0,1)$,  $X_2 \sim N(0,2^2)$,  $X_3 \sim N(5,3^2)$,  $p_i = P\{-2 \leq X_i \leq 2\}$ ( $i=1,2,3$), 则 ( )

A. $p_1 > p_2 > p_3$.

B. $p_2 > p_1 > p_3$.

C. $p_3 > p_1 > p_2$.

D. $p_1 > p_3 > p_2$.

<!-- source: 【横版】10-26年数一真题套卷做题本.pdf; PDF 第 77 页 -->

### 第 8 题

设随机变量  $X \sim t(n)$,  $Y \sim F(1,n)$, 给定  $a (0 < a < 0.5)$, 常数 c 满足  $P\{X > c\} = a$, 则  $P\{Y > c^2\} = (\quad)$

A. $\alpha$.

B. $1-\alpha$.

C. $2\alpha$.

D. $1-2\alpha$.

(II) 存在  $\eta \in (-1,1)$，使得  $f''(\eta) + f'(\eta) = 1$.

### 第 21 题（11 分）

设二次型  $f(x_{1},x_{2},x_{3})=2(a_{1}x_{1}+a_{2}x_{2}+a_{3}x_{3})^{2}+(b_{1}x_{1}+b_{2}x_{2}+b_{3}x_{3})^{2}$，记  $\alpha=\begin{pmatrix}a_{1}\\a_{2}\\a_{3}\end{pmatrix},\beta=\begin{pmatrix}b_{1}\\b_{2}\\b_{3}\end{pmatrix}$.

(I) 证明二次型 f 对应的矩阵为  $2\alpha\alpha^{T} + \beta\beta^{T}$;

(II) 若  $\alpha, \beta$ 正交且均为单位向量，证明 f 在正交变换下的标准形为  $2y_{1}^{2} + y_{2}^{2}$.

### 第 23 题（11 分）

设总体 X 的概率密度为  $f(x;\theta)=\left\{\begin{aligned}&\frac{\theta^{2}}{x^{3}}\mathrm{e}^{-\frac{\theta}{x}},&x>0,\\ &0,& 其他,\end{aligned}\right.$，其中  $\theta$ 为未知参数且大于零.  $X_{1},X_{2},\cdots,X_{n}$ 为来自总体 X 的简单随机样本.

(I) 求  $\theta$ 的矩估计量;

(II) 求  $\theta$ 的最大似然估计量.
