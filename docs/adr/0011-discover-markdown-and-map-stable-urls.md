# Check and discover Markdown with stable URLs

The static build checks the minimum compatibility and safety rules in `docs/repository-standard-v1.md`, then scans the selected Book Source Root recursively for UTF-8 `.md` and `.markdown` files while excluding hidden, dependency, and generated directories. A root `README.md` is the Entry Document when present; otherwise the first normalized path is used. Reading order follows a root `SUMMARY.md`, Markdown links in README lists, or normalized paths in that priority order; the Entry Document stays first and unlisted documents are appended. These controls are optional. The Entry Document maps to `/books/<slug>/`, and other documents preserve their normalized relative path after removing the Markdown extension. Repository-relative Markdown links map to those reader routes, while images and downloads map to the copied asset root without duplicating the source document directory. Recoverable shape and link problems are warnings rather than build failures. As specified in [ADR 0020](0020-select-book-roots-within-shared-repositories.md), `rootDirectory` defaults to the repository root; a subdirectory selection scopes README, SUMMARY, discovery, local links and assets to that book. Public paths omit the selected root prefix, while GitHub source links retain it.
