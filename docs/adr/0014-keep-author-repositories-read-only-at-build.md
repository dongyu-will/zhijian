# Keep author repositories read-only at build

The site build treats an author repository as untrusted content: it may clone and parse compatible Markdown and static assets, but it never executes repository scripts, workflows, package managers, or build commands. Discovery and asset copying skip symbolic links without dereferencing them, while references outside the selected Book Source Root remain unresolved. [ADR 0020](0020-select-book-roots-within-shared-repositories.md) additionally rejects symbolic links in the selected root path and limits asset copying to that root, never falling back to the enclosing repository. These content problems produce warnings when they are recoverable. This keeps the build boundary understandable and prevents repository content from reading or publishing files from the build host.
