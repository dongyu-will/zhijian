# 首发发布说明

## 发布范围

- 数学一、数学二 2010–2026 年整理文本和题目配图，各 17 份试卷。
- 网站只生成这两份资料的阅读页、搜索索引和 Markdown 源文件页。
- 模板只留在源码示例目录；不启用旧的外部演示资料。
- 原 PDF、未引用配图和 OCR 中间文件保留在本地；7 处题目配图随正文公开。
- 项目代码采用 MIT，资料的来源与权利单独说明。

## 构建

```sh
npm ci
npm run verify
npm run preview
```

`npm run verify` 包含首发产物检查：只有两份预期资料、各 17 份试卷，且发布资源不夹带 PDF、未引用图片、旧资料或模板页。此检查仅描述首发范围；今后增加资料时一并更新。

每次启动开发或构建时，会清空并重新生成 `public/book-assets/`，防止被移出收录范围的文件残留在发布包中。原件不放在这个生成目录。

## GitHub Pages

目标仓库为 `dongyu-will/zhijian`，站点地址为 <https://dongyu-will.github.io/zhijian/>。执行远端步骤前先确认本地改动和构建结果。

1. 以 `main` 为默认分支发布；公开前检查远端分支、标签及其历史，确保不包含原 PDF、本地临时文件或敏感信息。旧私有研发历史只保留在本地，不推送。
2. 将仓库设为公开，在 Settings → Pages 中选择 GitHub Actions。
3. 在 Actions 手动运行 **Build and Deploy Pages**，或向 `main` 推送提交触发部署。
4. 确认部署成功后，访问 Pages 给出的站点地址，检查首页两份资料、年份跳转、搜索和源文件链接。

工作流使用 GitHub Pages 返回的路径和域名，不依赖旧的 `/wiki` 设置。源文件链接使用构建提交 SHA，可追溯到同一版本。PR 执行完整验证，但不部署。

只有 GitHub Pages 工作流成功且线上页面实际可读，才算正式上线。源码中的配置与本地验证不代表站点已发布。
