# 02. 内容形式示例

这一章集中展示常用的 Markdown 内容形式。写自己的书时，只保留真正需要的部分。

## 普通正文与强调

正文适合连续解释。可以使用 **粗体突出结论**、用 *斜体标记语气*，或者用 `行内代码` 表示命令、字段和文件名。

> 引用块适合放置定义、原文摘录或需要读者特别留意的说明。

## 列表与任务

有顺序的步骤：

1. 说明输入。
2. 展示过程。
3. 给出结果。

可以检查的事项：

- [x] 标题清楚
- [x] 示例具体
- [ ] 补充更多参考资料

## 表格

| 内容形式 | 适合表达 |
| --- | --- |
| 段落 | 连续的解释和论证 |
| 列表 | 步骤、条件或并列事项 |
| 表格 | 多个对象的字段比较 |

## 代码

```js
function totalPrice(unitPrice, quantity) {
  return unitPrice * quantity;
}

console.log(totalPrice(25, 4)); // 100
```

## 公式

行内公式适合短关系，例如 $y = 2x + 1$。较重要的公式可以单独展示：

$$
P_{total} = P_{unit} \times Q
$$

其中 $P_{total}$ 是总价，$P_{unit}$ 是单价，$Q$ 是数量。
